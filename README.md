# EcoTour Belқарағай

**«Табиғатты таны. Тарихты сақта. Болашаққа жол аш!»**

Белқарағай ауылының табиғи және тарихи әлеуетін таныстыратын, интерактивті туристік картасы, маршруттары, тарихи уақыт шкаласы, экомониторинг формасы және QR-гиді бар веб-сайт.

Технологиялар: React 19 + TypeScript, Vite, Tailwind CSS v4, Lucide React, Leaflet + OpenStreetMap, React Router, localStorage.

---

## 1. Іске қосу

Компьютерде [Node.js](https://nodejs.org) (20 немесе одан жаңа нұсқа) орнатылған болуы керек.

```bash
# 1) Жоба бумасына кіру
cd ecotour-belqaragai

# 2) Пакеттерді орнату (бір рет қана, интернет қажет)
npm install

# 3) Әзірлеу режимінде іске қосу
npm run dev
```

Терминалда шыққан мекенжайды ашыңыз (әдетте `http://localhost:5173`).
Телефоннан тексеру үшін: телефон мен компьютер бір Wi-Fi желісінде болсын, терминалдағы `Network:` мекенжайын телефонда ашыңыз.

Басқа командалар:

| Команда | Не істейді |
|---|---|
| `npm run build` | TypeScript қателерін тексеріп, жарияланатын нұсқаны `dist/` бумасына жинайды |
| `npm run preview` | Жиналған `dist/` нұсқасын жергілікті түрде көрсетеді |
| `npm run typecheck` | Тек TypeScript тексеруі |

Пакеттерді жеке орнату керек болса:

```bash
npm install react react-dom react-router leaflet react-leaflet lucide-react qrcode @fontsource/lora @fontsource/onest
npm install -D vite @vitejs/plugin-react tailwindcss @tailwindcss/vite typescript @types/react @types/react-dom @types/leaflet @types/qrcode
```

## 2. Басты беттің видеосы

Видео мына жерде тұруы керек:

```
public/videos/belqaragai-intro.mp4
```

Сайт оны `/videos/belqaragai-intro.mp4` мекенжайы бойынша оқиды (`public` бумасындағы файлдар сайттың түбірінен ашылады).
Видеоны ауыстыру үшін жаңа файлды дәл осы атаумен сол бумаға салыңыз.

- Видео `autoplay`, `muted`, `loop`, `playsInline` режимінде ойнайды.
- Видео жүктелмесе немесе жоқ болса — `public/images/hero-poster.jpg` суреті, ол да болмаса — жасыл табиғи градиент фон көрсетіледі. Сайт істен шықпайды.
- Құрылғыда «қозғалысты азайту» (reduce motion) баптауы қосулы болса, видео тоқтап, тек постер көрсетіледі.
- Ұсыныс: видео көлемі 10 МБ-тан аспасын, H.264 (MP4) форматында болсын.

## 4. Нақты деректерді қайда өзгертуге болады

**Барлық мазмұн `src/data/` бумасында.** Компоненттердің ішін өзгертудің қажеті жоқ.

### Нысандар — `src/data/places.ts`

Қазір онда толтыруға арналған **үлгі жазбалар** тұр (атауы, координаты ойдан жазылмаған). Әр нысан:

```ts
{
  id: 'orman-alqaby',                 // латын әрпімен, бос орынсыз — QR сілтемесінде қолданылады
  name: 'Нысанның нақты атауы',
  category: 'nature',                 // nature | history | recreation | route | eco
  description: 'Қысқаша сипаттама',
  historicalSignificance: 'Тарихи немесе табиғи маңызы',
  latitude: null,                     // расталса: 49.123456
  longitude: null,                    // расталса: 85.123456
  image: null,                        // '/images/places/orman.jpg'
  source: 'Дереккөз: кітап, беті / сілтеме / куәгер',
  verified: false,                    // тексерілгенде ғана true
}
```

Ережелер:
- Координат расталмаса — `null` қалдырыңыз. Нысан тізімде «Координат нақтылануда» деп көрінеді, картаға шықпайды.
- Координат бар, бірақ `verified: false` болса — картада **сұр, үзік жиекті** «Тексерілмеген» белгі болып шығады.
- Тек `verified: true` және координаты бар нысан ғана «Тексерілген нүкте» болып есептеледі.
- Нысанның суретін `public/images/places/` бумасына салыңыз.
- Координатты анықтау: [openstreetmap.org](https://www.openstreetmap.org) → нүктені тінтуірдің оң жағымен басу → «Show address» немесе жергілікті жерде телефонның GPS-і арқылы.

**Картаның бастапқы көрінісі** — `src/data/site.ts` → `MAP_DEFAULT_VIEW`. Қазір ол Катонқарағай ауданы аумағына **шамамен** бағытталған (туристік нүкте емес). Белқарағай ауылының расталған координатын жазып, `zoom` мәнін 13–14 етіңіз. Нысандардың координаттары енгізілгенде карта оларға автоматты түрде сәйкестенеді.

### Маршруттар — `src/data/routes.ts`
- `distance`, `duration`, `difficulty` — расталмаса `null` (сайтта «Нақтылау қажет» шығады).
- `placeIds` — маршрутқа кіретін нысандардың `id` мәндері, ретімен.
- `verifiedPath` — нақты жол сызығы (`[[ендік, бойлық], ...]`). Тексерілген GPS-трек болғанда және маршруттың барлық нүктесі `verified: true` болғанда ғана сызылады.

### Тарих — `src/data/history.ts`
«Жер жаннаты – Катонқарағай» кітабының үзінділерін осы жерге енгізіңіз: `period` (жыл/кезең), `text` (мәтін), `source` (кітап атауы, авторы, басылым жылы, беті).
Мәтіні немесе дереккөзі жоқ материал сайтта «Мәлімет нақтылануда» деп белгіленеді.

### Жергілікті қызметтер — `src/data/services.ts`
Тек иелерінің келісімімен берілген, расталған деректерді `entries` ішіне жазыңыз. Бос болса — «Толтыруға арналған үлгі» көрсетіледі.

### Атауы, ұраны, видео жолы — `src/data/site.ts`

## 5. Не толық жұмыс істейді, не демо режимде

| Функция | Күйі |
|---|---|
| Видео-фоны бар басты бет, навигация, телефондағы ықшам мәзір | ✅ толық |
| Интерактивті карта (Leaflet + OpenStreetMap): үлкейту/кішірейту, белгілер, ақпараттық терезе | ✅ толық (интернет қажет) |
| Санат бойынша сүзгі, атауы бойынша іздеу, тізім ↔ карта байланысы, «Картадан көрсету» | ✅ толық |
| Маршрут беті: нүктелер тізімі және картадағы нүктелер | ✅ толық |
| Тарихи уақыт шкаласы | ✅ толық (мазмұны толтырылуы керек) |
| Нысанның жеке беті `/place/:id` | ✅ толық |
| QR-код жасау, PNG жүктеу, карточканы басып шығару | ✅ толық (сайт интернетке жарияланғанда) |
| Жоба нәтижелері (сандар) | ✅ сайттағы нақты деректерден автоматты есептеледі |
| Экологиялық хабарлама формасы | ⚠️ **демо**: өрістер тексеріледі, бірақ хабарлама тек **осы браузердің localStorage** жадында сақталады. Ешқандай ұйымға жіберілмейді. |
| Демо-басқару беті `/admin` | ⚠️ **демо**: құпиясөз де, серверлік авторизация да **жоқ**. Бұл қауіпсіз әкімші жүйесі емес. Деректер тек осы браузерде. |
| Басқару бетінен қосылған нысандар | ⚠️ тек осы браузерде көрінеді. Барлығына көріну үшін «JSON ретінде көшіру» батырмасымен көшіріп, `places.ts`-ке қосыңыз. |

Нақты серверге қосу (болашақта): хабарламаларды Firebase, Supabase немесе Google Forms сияқты қызметке жіберуге болады — ол үшін `src/lib/store.ts` ішіндегі `addReport` функциясын өзгерту жеткілікті.

### Интернетсіз жұмыс
Карта плиткалары (суреттері) OpenStreetMap серверінен жүктеледі. Интернет болмаса, картаның үстінде ескерту шығады, ал нысандар тізімі толық қолжетімді болып қалады. Қаріптер жобаның ішінде, сондықтан қазақ әріптері интернетсіз де дұрыс көрінеді.

> Комиссия алдында көрсетуге кеңес: интернет болмауы мүмкін болса, сайтты алдын ала бір рет ашып, картаны қажетті жерде үлкейтіп қойыңыз (браузер плиткаларды кэште сақтайды).

## 6. QR-гид және сайтты интернетке жариялау

QR-код **тек интернетте жұмыс істейтін жария мекенжай** үшін жасалады.
`http://localhost:5173` — жергілікті тест мекенжайы: ол тек сіздің компьютеріңізде ашылады, басқа адамның телефоны оны аша алмайды. Сондықтан QR-гид беті мұндай мекенжайға код жасамайды.

Сайтты тегін жариялау (мысалы, Netlify):
1. `npm run build` — `dist/` бумасы пайда болады.
2. [app.netlify.com/drop](https://app.netlify.com/drop) бетіне `dist` бумасын сүйреп апарыңыз.
3. Берілген мекенжайды (мысалы `https://ecotour-belqaragai.netlify.app`) көшіріңіз.

### GitHub Pages
Репозиторийде `.github/workflows/deploy.yml` бар: `main` тармағына әр push жасалғанда сайт автоматты түрде жиналып,
`https://<пайдаланушы>.github.io/ecotour-belqaragai/` мекенжайына жарияланады.
Бір рет баптау: репозиторий → **Settings → Pages → Source: GitHub Actions**.
Репозиторий атауын өзгертсеңіз, `vite.config.ts` ішіндегі `PAGES_BASE` мәнін де өзгертіңіз.
GitHub Pages-те QR-гид мекенжайды өзі анықтайды (`…github.io/ecotour-belqaragai`).

Тұрақты мекенжайды QR үшін бекіту: `.env.example` файлын `.env` деп көшіріп, ішіне жазыңыз:

```
VITE_SITE_URL=https://ecotour-belqaragai.netlify.app
```

Содан кейін қайта `npm run build` жасап, жариялаңыз. (Мекенжайды QR-гид бетінде қолмен енгізуге де болады.)

`public/_redirects` (Netlify) және `vercel.json` (Vercel) файлдары `/place/...` сияқты беттерді тікелей ашқанда (QR сканерлегенде) 404 қатесі шықпауы үшін қажет.

## 7. Суреттер туралы

`public/images/` ішіндегі суреттер — берілген видеодан алынған **көрнекі иллюстрациялар** (сайтта «Иллюстрация» деп белгіленген). Олар Белқарағайдың нақты фотосы ретінде ұсынылмайды. Жергілікті жерде түсірілген нақты фотолармен ауыстыру ұсынылады (файл атауларын сақтасаңыз, кодты өзгертудің қажеті жоқ).
